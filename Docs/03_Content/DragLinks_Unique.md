# Drag Links! — Unique & Numeric Growth

> 문서 버전: 0.2  
> 기준일: 2026-08-25

## 1. 성장 종류

[확정] 상점에서 구매 가능한 성장 종류는 크게 두 개다.

1. 유니크
2. 수치형

[확정] 현재 기획에서는 소모품을 사용하지 않는다.

## 2. 유니크 분류

### 액티브
조건이 충족된 뒤 플레이어가 원하는 시점에 직접 사용.

예:
- 유니크9

### 일반형 패시브
획득하면 게임 규칙/보드에 자동 반영.

예:
- 유니크4
- 기존 구상 유니크6, 8

### 반응형 패시브
특정 조건을 만족하는 순간 자동 발동.

예:
- 유니크1
- 기존 구상 유니크3, 5

## 3. 수치형 성장

현재 방향:
- 숫자 등장 확률 조정
- 연산자 등장 확률 조정
- 약수 추가 배율 업그레이드
- 플레이어 전용 능력 레벨업

[미정] 정확한 수치와 가격.

## 4. 유니크1

분류:
반응형 패시브

조건:
숫자 1 **고유 속성** 타일을 총 5번 사용.

발동:
현재 보드에 존재하는 모든 숫자 1 고유 속성 타일의 **현재 숫자값 +10**.

### 사용 판정

현재 확정:
- 정상 수식에 포함된 숫자 1 → 사용 횟수 +1
- LINKING으로 실제 제거되는 숫자 1 → 사용 횟수 +1
- 한가은 5스택으로 파괴되는 보석 숫자 1 → 사용 횟수 +0

이유:
- 수식 / LINKING 제거 → 연산 + 사용
- 5스택 제거 → 파괴이며 연산/사용 아님

상세:
`Docs/01_Gameplay/DragLinks_Judgements.md`

### 현재값과 Identity

현재 숫자값이:
- 11
- 21
- 2140

처럼 변해 있어도 NumberIdentity가 1이면 사용 카운트에 포함된다.

+10 발동으로 CurrentValue가 변해도 NumberIdentity와 색은 유지된다.

[미정]
- 5회 발동 뒤 카운트 초기화 여부
- 반복 발동 여부
- 한 번에 5회를 초과했을 때 나머지 카운트 이월

## 5. 교차 LINKING과 유니크1

가로/세로 LINKING이 교차하면 교차 타일은 실제로 한 번만 제거된다.

[현재안] 교차점의 숫자 1 사용 카운트도 실제 제거 기준 1회로 기록한다.

이벤트 카운트 구현 전 필요하면 최종 확인한다.

## 6. 유니크4

분류:
일반형 패시브

효과:
보드 타일이 체스판처럼 숫자와 연산자가 번갈아 배치되는 구조를 만든다.

[미정]
- 7×6/8×6에서의 정확한 배치 알고리즘
- 대각선 드래그와 LINKING 환경에서 밸런스

## 7. 유니크9

분류:
액티브

현재안:
- 약 3턴마다 사용 가능
- 사용 후 숫자 타일 하나 선택
- 현재 고유 숫자 속성을 제외한 다른 8개 속성 중 하나로 변경

[확정] 현재 기획에서 숫자 타일의 **고유 숫자 속성 자체를 바꿀 수 있는 예외**다.

예:
- CurrentValue 21
- NumberIdentity 1
- 유니크9로 Identity 2 변경
- CurrentValue 21 유지
- 이후 숫자 2 속성/색으로 취급

[미정]
- 정확한 쿨다운
- 최초 사용 가능 상태
- 연산자 합성 턴도 쿨다운 진행에 포함되는지
- UI 방식

## 8. 초기 유니크 선택

[현재안] 게임/런 시작 시 무료 유니크 하나를 선택하는 구조를 사용한다.

[현재안] Stage 클리어 후 상점 구조는 전작 Mathcalibur의 장점을 참고한다.

현재 첫 구현에서는 유니크1을 우선 대상으로 한다.

상점 상세는 현재 우선 구현 대상이 아니다.

## 9. 구현 원칙

- 유니크 효과를 Board 공통 코드에 직접 하드코딩하지 않는다.
- 발동 타이밍을 명시할 수 있는 구조를 사용한다.
- `사용`, `파괴`, `상승변화` 등을 문자열/애니메이션이 아니라 명시적인 Gameplay 판정으로 구분한다.
- 타일 이벤트/사용 판정을 구독할 수 있는 방향으로 확장한다.
- 획득 데이터와 런타임 상태를 분리한다.
- `[미정]` 규칙을 구현 편의상 임의 확정하지 않는다.
