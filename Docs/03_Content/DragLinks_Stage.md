# Drag Links! — Stage Rules

> 문서 버전: 0.1  
> 기준일: 2026-08-25

## 1. 스테이지 공통

각 스테이지는 다음 요소를 데이터로 가질 수 있다.

- Stage ID
- 목표 점수
- 제한 턴
- 적/고민 몬스터
- 적 기믹
- 보드 설정
- 배경/연출
- BGM
- 사용 가능한 특수 요소

[확정] 스테이지마다 목표 점수는 다를 수 있다.

[확정] 스테이지마다 방해 기믹이 다를 수 있다.

## 2. Stage 0

[확정] 현재 Stage 0은 없다.

첫 제작 대상은 Stage 1이다.

## 3. Stage_01 씬

현재 Unity 씬 이름:
`Stage_01`

주의:
- 씬은 Stage 1 콘텐츠를 보여주지만 핵심 Gameplay 시스템은 Stage 1 전용으로 만들지 않는다.
- Stage 데이터와 범용 Stage Controller를 사용하는 구조를 지향한다.

## 4. Stage 1 현재 첫 구현 기준

| 항목 | 현재안 |
|---|---|
| 목표 플레이타임 | 약 4~5분 [임시] |
| 목표 점수 | 1000 [임시] |
| 제한 턴 | [미정] |
| 숫자 | 기본 1~9 |
| 연산자 | +, -, ×, ÷ 모두 등장 |
| 역수 | 미사용 |
| 플레이어 | 한가은 |
| 캐릭터 능력 | 보석/망치 |
| 초기 유니크 | 우선 유니크1 |
| 보드 크기 | 7×6 / 8×6 [미정] |

## 5. Stage 1 사건

[현재안] 전교 10등 안에 들지 못한 학생의 고민을 다룬다.

내면 세계에서 고민은 **문제집 형태의 몬스터**로 나타난다.

한가은이 S.A.V.E 신입으로 처음 실제 활동을 하며 상대하는 대상이다.

## 6. Stage 1 적 기믹

현재안:
- 2턴마다 발동
- 1~100 중 하나를 무작위로 뽑음
- 성적 0~100점처럼 보이는 연출
- 뽑힌 수의 일의 자리 숫자만큼 플레이어에게 불이익

예:
- 37 → 7
- 80 → 0
- 100 → 0

[미정] 정확히 어떤 값을 감소시키는가.

[임시] 2턴 주기 및 1~100 랜덤 방식은 실제 플레이 테스트로 조정 가능하다.

## 7. 스폰 확률

[임시] 초기 숫자/연산자 출현 가중치는 Mathcalibur 최종 구현의 값을 참고하여 시작할 수 있다.

중요:
- Drag Links!는 보드 크기와 대각선 드래그, LINKING 규칙이 다르므로 전작 수치를 최종값으로 취급하지 않는다.
- 모든 가중치는 Config에서 조정 가능해야 한다.

## 8. Stage 2 이후 계획 — 역수

[현재안] 역수는 Stage 2 이후 방해 요소로 등장할 수 있다.

의도:
- 단순 불리한 타일
- 나눗셈과 결합하면 결과적으로 곱셈처럼 활용할 수 있는 양면적 퍼즐 요소

[미정]
- 타일 형태
- 생성 방식
- 고유 숫자 속성
- 분수 계산
- 점수 배율과의 관계

## 9. 스테이지 클리어

[확정] 누적 점수가 목표 점수 이상이면 클리어 조건 충족.

[미정]
- 클리어 직후 연출
- StoryScene 복귀 시점
- 상점 진입 방식
- 초과 점수 보상
- 남은 턴 보상

## 10. 향후 Stage 확장 원칙

새 Stage를 만들 때 공통 코드를 복사하지 않는다.

가능하면:
- `StageDefinition`
- `EnemyDefinition`
- `EnemyRule`

같은 데이터/행동 조합으로 확장한다.
