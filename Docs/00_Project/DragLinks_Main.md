# Drag Links! — Main Game Design

> 문서 버전: 0.2  
> 기준일: 2026-08-25  
> 상태: 현재 프로젝트의 최상위 게임 규칙

## 1. 프로젝트 정의

**Drag Links!**는 PC용 캐주얼 퍼즐 게임이다.

플레이어는 숫자와 연산자 타일을 드래그하여 수식을 만들고, 제한된 턴 안에 스테이지별 목표 점수에 도달해야 한다.

스토리에서는 S.A.V.E 동아리의 멤버들이 고민이나 절망을 가진 사람의 내면 세계로 들어가 문제를 해결한다.

## 2. 프로젝트의 중요한 전제

[확정] Drag Links!는 Mathcalibur의 리메이크나 후속 개조 프로젝트가 아니다.

전작에서 참고하는 것은 다음과 같은 **강점과 구현 경험**이다.

- 보드 기반 숫자/연산자 퍼즐
- 드래그로 수식을 만드는 조작
- 사용 타일 제거
- 중력
- 빈칸 충당
- 자동 줄 처리와 연속 처리
- 경로를 역순으로 되짚어 드래그를 취소하는 UX

Drag Links!의 세계관, 캐릭터, 목표 점수 방식, 캐릭터 능력, LINKING, 연쇄 콤보, 성장 구조는 신규 설계다.

## 3. 한 줄 설명

> 숫자와 연산자를 드래그해 수식을 만들고, 보드를 성장시키며 LINKING과 캐릭터 연쇄 콤보를 쌓아 제한 턴 안에 목표 점수를 달성하는 PC 캐주얼 퍼즐 게임.

## 4. 게임 목표

[확정] 각 스테이지에는 목표 점수가 존재한다.

[확정] 플레이어는 주어진 턴 안에 누적 점수가 목표 점수 이상이 되도록 해야 한다.

[확정] 목표 점수에 도달하면 승리한다.

[확정] 시간 제한은 없다.

[미정] 목표 점수를 초과한 점수가 별도 보상에 영향을 주는지 여부.

[미정] 남은 턴이 별도 보상에 영향을 주는지 여부.

## 5. 게임의 핵심 재미

### 5.1 직접 수식을 만드는 드래그

숫자와 연산자를 손으로 이어 실제 수식을 만든다.

### 5.2 값이 성장해도 정체성을 유지하는 숫자 타일

숫자 타일은 게임 중 +1, +10, 배율 등으로 현재 숫자값이 변할 수 있다.

그러나 일반적인 변화로는 **그 타일이 본래 어떤 숫자 속성인지**가 바뀌지 않는다.

예:
- 파란색이 숫자 1 속성이라고 가정
- 파란 1이 +10을 받아 파란 11이 됨
- 계산에는 11을 사용
- "숫자 1 속성을 사용했다"는 조건에는 여전히 포함

### 5.3 큰 숫자와 좋은 약수 사이의 점수 전략

수식 결과가 크면 기본 점수가 커지고, 동시에 1~9 중 여러 숫자로 나누어떨어지는 결과를 만들면 추가 배율을 받는다.

### 5.4 LINKING과 지속형 연쇄 콤보

수식 처리 후 보드가 내려오고 새 타일이 들어오는 과정에서 가로 또는 세로 한 줄 전체가 숫자 타일이 되면 **연쇄 보너스**가 발생한다.

화면 연출 명칭은 **LINKING!**이다.

LINKING으로 실제 제거되는 숫자 타일은 수식에 사용된 숫자처럼 **연산/사용 판정**으로 기록된다.

한가은의 **연쇄 콤보 스택은 턴을 넘어 유지**된다.

한 번의 보드 정산에서 LINKING 라인이 여러 개 발생하면 그 수만큼 콤보 정산 횟수를 얻고, LINKING 자체를 모두 해결한 뒤 현재 스택에서부터 하나씩 순차적으로 효과를 발동한다.

5스택 효과 발동 후에는 스택이 0으로 초기화된다.

### 5.5 플레이어블 캐릭터마다 다른 퍼즐 능력

현재 첫 플레이어블 캐릭터는 한가은이다.

한가은은 숫자 타일의 **보석 속성**과 연산자 타일의 **망치 속성**을 이용한다.

향후 다른 S.A.V.E 멤버가 다른 마스코트, 무기, 능력을 가진 플레이어블 캐릭터로 추가될 수 있다.

## 6. 현재 보드 및 타일 개요

[미정] 보드 크기는 `7×6` 또는 `8×6`을 검토 중이다.

[확정] 보드 크기는 코드 하드코딩이 아니라 Config로 변경 가능해야 한다.

[확정] 숫자 타일의 기본 생성 숫자는 1~9다.

[확정] 숫자 1~9는 각각 서로 다른 고유 색을 가진다.

[확정] 연산자 타일은 공통 한 가지 색 계열을 사용한다.

[확정] 연산자는 `+`, `-`, `×`, `÷`를 사용한다.

[확정] 타일 외형은 모서리가 둥근 정사각형 2D 에셋을 기본으로 한다.

[확정] 숫자와 연산자 표시는 타일 배경과 별도의 에셋/표현 계층으로 관리한다.

[확정] 보드 관련 에셋도 2D를 기본으로 한다.

[확정] 보석은 팔각형 보석 이미지로 표현할 예정이다.

## 7. 현재 핵심 용어

| 용어 | 의미 |
|---|---|
| Link | S.A.V.E 멤버가 고민/절망하는 사람의 마음속 세계로 들어가는 행위 |
| Drag | 플레이어가 보드의 타일을 이어가는 기본 입력 |
| 연쇄 보너스 | 타일 재배치/충당 이후 숫자 타일이 한 줄을 완성해 자동으로 제거되는 현상 |
| LINKING! | 연쇄 보너스 발생 시 표시되는 연출 명칭 |
| LINKING Wave | 한 번의 검사에서 동시에 발견된 가로/세로 LINKING 라인 묶음 |
| 연쇄 콤보 스택 | 한가은이 턴을 넘어 유지하는 0~4의 현재 단계 상태. 5에 도달하면 5스택 효과 후 0으로 초기화 |
| 콤보 정산 대기 횟수 | 아직 연쇄 콤보 스택 증가/효과로 소비하지 않은 LINKING 라인 수 |
| 보석 | 한가은 능력으로 숫자 타일에 부여되는 특수 속성 |
| 망치 | 한가은 능력으로 연산자 타일에 부여되는 특수 속성 |
| 사용 | 수식 또는 LINKING 등에서 실제로 사용된 타일 판정 |
| 파괴 | 사용/연산과 별개로 타일을 직접 제거하는 판정 |
| 상승변화 | 현재 숫자값을 증가시키는 변화 판정 |
| 유니크 | 특정 조건, 규칙, 캐릭터 빌드를 변화시키는 성장 요소 |
| 수치형 | 확률, 배율, 능력 레벨 등에 직접 반영되는 성장 요소 |

## 9. 현재 구현 마일스톤

현재 `Stage_01`에서 다음 첫 Gameplay 기반이 구현되었다.

- 보드 생성/표시
- 8방향 드래그
- Number/Operator 교대
- Backtrack
- 유효 경로 제거
- Gravity/Refill
- LINKING 탐색 및 반복 해결

다음 큰 구현 대상:
1. 최신 지속형 연쇄 콤보 Runtime 구조
2. 한가은 보석/망치 능력
3. 실제 수식 계산
4. 점수 시스템
5. 연산자 합성
6. 목표 점수/턴
7. Stage_01 적 기믹
8. 유니크

정확한 순서는 개발 상황에 따라 조정할 수 있다.

## 10. 현재 주요 미정

- 보드 최종 크기: 7×6 / 8×6
- 시작 보드에 LINKING을 허용할지
- 보드 최소 허용 크기
- Stage_01 제한 턴
- 목표 점수 초과분 보상
- 남은 턴 보상
- 최종 수식 결과가 음수일 때 처리
- 비정수 결과에 약수 배율을 적용하는 방법
- `××`, `÷÷`, 서로 다른 연산자 합성
- 수식에 보석이 4개 이상일 때 망치가 처리할 3개 우선순위
- 한가은 5스택의 강제 보석 파괴가 일반 3×3 보석 폭발 효과도 일으키는지 여부
- 적 기믹이 정확히 감소시키는 대상
- Stage 2 역수 세부 규칙
- 챌린지 모드 세부 구조
- 상점 세부 구조
