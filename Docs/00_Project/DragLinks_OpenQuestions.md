## 1. 보드

- [미정] 보드 Config의 최소 허용 Width/Height
- [미정] 최종 숫자 1~9 RGB 팔레트

- [미정] 최종 Number/Operator 및 개별 타일 스폰 가중치

## 2. LINKING

### 2.1 LINKING 1회마다 전체 숫자 +1 여부

과거 기획에는 다음 규칙이 있었다.

> LINKING/보너스가 한 번 발생할 때마다 보드의 모든 숫자 타일 값 +1.

최신 지속형 연쇄 콤보 규칙에서는 이 효과를 별도로 다시 확정하지 않았다.

따라서 현재 구현 전 확인 필요.

### 2.2 교차 LINKING의 교차 타일 사용 이벤트

[현재안]
- 라인 수는 각각 센다.
- 교차 타일은 실제로 한 번만 제거한다.
- 따라서 동일 타일의 사용 판정도 한 번만 기록하는 방향이 자연스럽다.

유니크 이벤트 카운트 구현 전에 필요하면 최종 확인한다.

## 3. 한가은

- [미정] 수식에 보석이 4개 이상일 때 망치가 터뜨릴 3개의 우선순위
- [미정] 5스택의 강제 보석 파괴가 일반 수식 보석의 3×3 폭발 효과까지 함께 발생시키는지 여부

참고:
- 6스택 규칙은 더 이상 필요하지 않는다.
- 5스택에서 스택이 0으로 초기화되고 남은 콤보 정산 대기 횟수는 다시 1스택부터 처리한다.
