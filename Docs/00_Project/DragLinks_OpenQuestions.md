## 2. LINKING 관련 확인 필요

### 2.1 LINKING 1회마다 전체 숫자 +1 여부

과거 기획에는 다음 규칙이 있었다.

> 보너스 어택/콤보 보너스가 한 번 발생할 때마다 보드의 모든 숫자 타일 값 +1.

이후 명칭이:
- 연쇄 보너스 = LINKING!
- 연쇄 콤보 = 누적 스택

으로 변경되었고 연쇄 콤보 단계별 효과도 수정되었으나, 위 **LINKING 1회당 전체 숫자 +1 규칙을 폐기한다는 명시적 결정은 아직 없음.**

따라서 현재 구현 전 확인 필요.

### 2.2 LINKING 라인 타일의 "사용 판정"

과거 기획에는 LINKING/보너스에 포함된 타일이 **사용 판정**을 받는 규칙이 있었다.

이 규칙이 유지된다면:
- 유니크1 같은 "숫자 1을 N회 사용" 조건에 LINKING 제거 타일이 영향을 줄 수 있음.

최신 수정에서 폐기 여부가 명시되지 않았으므로 구현 전 확인 필요.
