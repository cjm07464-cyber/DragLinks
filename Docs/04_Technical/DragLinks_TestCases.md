> 문서 버전: 0.1

이 문서는 출시용 프로젝트에서 최소한 검증해야 할 핵심 규칙을 정리한다.

# A. Drag

## A-01 숫자 시작 기본
`1 → + → 2`

기대:
- 유효 수식
- 드래그 길이 3
- 손을 떼면 1턴 소비

## A-02 숫자→숫자 직접 연결
`1` 선택 후 인접 숫자 `2`로 이동.

기대:
- 연결되지 않음

## A-03 대각선
숫자와 연산자가 대각선 인접.

기대:
- 타입 규칙이 맞으면 연결 가능

## A-04 재사용
`A → B → C` 후 A 재진입.

기대:
- 불가

## A-05 되돌리기
`A → B → C` 후 C에서 B로 이동.

기대:
- C 선택 취소
- Path = A,B

## A-06 최대 길이
기본 MaxDragLength=5.

기대:
- 5개까지
- 6번째 추가 불가

## A-07 미완성 수식
`1 → +` 후 입력 종료.

기대:
- 무효
- 턴 미소비

## I-01 1스택

## I-02 2스택
기대:

- 오류 없음

- 크래시 없음
- 효과 자체는 [미정]

## J-04 연산자 합성

## K-02 2턴 적 기믹

- 실제 감소 대상은 [미정]이므로 그 값은 테스트하지 않음

# L. 미정 규칙 테스트 정책

`[미정]` 규칙은:
- 임의 예상값을 Expected Result로 적지 않는다.
- Pending/Ignore 또는 Unsupported 상태로 관리한다.
- 기획 확정 후 본 테스트로 승격한다.
