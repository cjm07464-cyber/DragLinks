# Drag Links! — Character System

> 문서 버전: 0.1  
> 기준일: 2026-08-25

## 1. 플레이어블 캐릭터 방향

[확정] 현재 첫 플레이어블 캐릭터는 한가은이다.

[확정] 향후 서로 다른 능력을 가진 다른 S.A.V.E 멤버를 플레이어블 캐릭터로 추가할 계획이다.

따라서 현재 한가은 능력을 게임 공통 Board/Linking 규칙에 직접 박아 넣지 않는다.

## 2. 캐릭터와 마스코트

[확정] S.A.V.E 멤버마다 각자의 마스코트가 있다.

[확정] Link를 통해 사람의 내면 세계에 들어가면 마스코트가 해당 캐릭터의 전용 무기로 변화한다.

[확정] 한가은의 마스코트는 내면 세계에서 망치로 변화한다.

향후 다른 캐릭터는 다른 마스코트/무기/능력을 가질 수 있다.

## 3. 캐릭터 능력의 책임

캐릭터 능력 시스템은 다음과 같은 타이밍에 반응할 수 있는 구조를 목표로 한다.

예:
- 게임 시작
- 턴 시작
- 수식 확정
- 수식 계산 후
- 타일 사용
- LINKING 발생
- 최종 연쇄 콤보 확정
- 턴 종료

모든 캐릭터가 모든 타이밍을 사용할 필요는 없다.

## 4. 공통 규칙과 캐릭터 규칙 분리

### 공통 게임 규칙
- 보드
- 타일
- 드래그
- 수식
- 점수
- 중력/충당
- LINKING 탐색
- 연쇄 콤보 스택 계산

### 한가은 전용
- 숫자 타일의 보석
- 연산자 타일의 망치
- 망치/보석 수식 효과
- 연쇄 콤보 단계별 보석 효과
- 턴 종료 시 랜덤 보석/망치 부여

이 분리는 향후 캐릭터 추가를 위해 반드시 유지한다.

## 5. 기술 확장 방향

[현재안] 캐릭터 Definition과 Runtime Ability를 분리한다.

예:
- `CharacterDefinition`
- `ICharacterAbility`
- `HangaeunAbility`

캐릭터 데이터:
- ID
- 표시 이름
- 마스코트/무기 참조
- UI 리소스
- 능력 구현 참조/타입

런타임 계산은 Definition 에셋 자체에 누적 상태를 저장하지 않는다.

## 6. 현재 미래 확장 미정

[미정]
- 다른 플레이어블 캐릭터 수
- 캐릭터 해금 방식
- 캐릭터별 성장
- 한 스테이지 중 캐릭터 교체 가능 여부
- 마스코트별 추가 능력
