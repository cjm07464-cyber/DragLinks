# Drag Links! — Hangaeun Ability

> 문서 버전: 0.1  
> 기준일: 2026-08-25

## 1. 캐릭터

이름: 한가은

- 고등학교 1학년
- 특별상담지원부 S.A.V.E 신입
- 수학을 자신의 강점으로 생각함
- 다른 사람의 내면 세계에서 산술 퍼즐 방식으로 문제를 해결함

[확정] 주인공 외형은 별도로 공유된 캐릭터 시안의 B안이 채택되었다.

이 문서에서는 외형을 묘사하지 않는다.

## 2. 마스코트와 무기

[확정] 한가은의 마스코트는 Link 후 내면 세계에서 **망치**로 변한다.

한가은의 퍼즐 능력은 보드의 **보석 숫자 타일**과 **망치 연산자 타일**을 이용한다.

## 3. 특수 속성 주체

[확정]
- 보석 속성 → 숫자 타일
- 망치 속성 → 연산자 타일

보석/망치는 원래 타일의 숫자값/숫자 속성/연산자 종류를 대체하지 않는다.

추가 특수 상태로 취급한다.

## 4. 게임 시작 및 턴 종료 기본 능력

발동 타이밍:
- 게임 최초 시작 시
- 한 턴의 모든 계산, LINKING, 연쇄 콤보 처리가 끝난 뒤

효과:
1. 현재 보드의 **보석이 아닌 숫자 타일** 중 무작위 1개에 보석 속성 부여
2. 현재 보드의 **망치가 아닌 연산자 타일** 중 무작위 1개에 망치 속성 부여

[확정] 각각 한 개만 선택한다.

[확정] 이미 보석/망치인 타일은 후보에서 제외한다.

[확정] 기존에 부여된 보석/망치는 해당 상태가 제거될 때까지 유지된다.

[현재안] 해당 종류의 유효 후보가 하나도 없으면 그 부여는 건너뛴다.

## 5. 수식 안의 망치와 보석

[확정] 하나의 정상 수식 안에 다음 두 요소가 모두 포함되면 한가은 능력의 수식 효과가 발동한다.

- 망치 속성을 가진 연산자
- 보석 속성을 가진 숫자 타일

망치와 보석이 수식에서 바로 붙어 있을 필요는 없다.

## 6. 망치의 역할

[확정] 망치는 트리거 역할을 한다.

[확정] 수식에 망치가 여러 개 있어도 드래그 순서상 가장 앞에 있는 망치 하나가 발동 주체가 된다.

[확정] 망치 하나는 같은 수식 안의 보석을 최대 3개까지 터뜨릴 수 있다.

[미정] 수식에 보석이 4개 이상 들어왔을 때 어떤 3개를 우선할지.

## 7. 일반 보석 폭발

보석 숫자 타일이 망치 효과로 터지면 해당 보석을 중심으로 **3×3 범위**를 확인한다.

[확정] 현재 드래그 수식에 포함된 타일은 주변 효과 대상에서 제외한다.

주변 대상:
- 일반 숫자 타일 → 보석 속성 부여
- 일반 연산자 타일 → 망치 속성 부여
- 이미 보석인 숫자 → 그대로 유지
- 이미 망치인 연산자 → 그대로 유지

[확정] 새로 보석/망치가 된 타일이 즉시 다시 폭발하는 추가 연쇄는 발생하지 않는다.

[확정] 수식 계산과 점수 처리를 먼저 완료한 뒤 보석/망치 효과를 처리한다.

## 8. 연쇄 콤보 능력

연쇄 콤보는 LINKING 시스템이 계산한 최종 스택을 전달받아 한가은 능력에서 처리한다.

### 1스택
현재 보드의 보석이 아닌 숫자 타일 중 최대 2개에 보석 속성을 부여한다.

### 2스택
현재 보드의 보석이 아닌 숫자 타일 중 최대 5개에 보석 속성을 부여한다.

### 3스택
현재 보드의 보석이 아닌 숫자 타일 중 최대 7개에 보석 속성을 부여한다.

### 4스택
1. 현재 보드의 보석이 아닌 숫자 타일 중 최대 9개에 보석 속성을 부여
2. 현재 보드의 모든 보석 수를 `n`으로 계산
3. 모든 보석 숫자 타일에서 **보석 속성만 제거**
4. 현재 보드에 남아 있는 모든 숫자 타일의 현재 숫자값을 `+n` 상승

### 5스택
1. 현재 보드의 보석이 아닌 숫자 타일 중 최대 11개에 보석 속성을 부여
2. 현재 보드의 모든 보석 수를 `n`으로 계산
3. 모든 보석 숫자 타일에서 **보석 속성만 제거**
4. 현재 보드에 남아 있는 모든 숫자 타일의 현재 숫자값을 `+n` 상승

## 9. 4~5스택의 중요한 규칙

[확정] "모든 보석이 터진다"는 숫자 타일 삭제가 아니다.

예:
- 숫자 1 고유 속성
- 현재 숫자값 31
- 보석 속성 보유

연쇄 콤보에서 보석이 터지면:
- 타일 그대로 존재
- 현재 숫자값 31 유지
- 숫자 1 속성 유지
- 색 유지
- 보석 속성만 제거

그 후 전체 숫자값 +n 효과를 받는다.

목적:
- 플레이어가 키운 숫자 타일을 연쇄 콤보 때문에 잃지 않게 함
- 누적한 보석을 숫자 성장으로 환원
- 보석 제거 때문에 새 빈칸이 생겨 LINKING 루프가 다시 시작되는 문제 방지

## 10. 4~5스택 보석 제거와 일반 보석 폭발의 차이

[미정] 연쇄 콤보에서 전체 보석 속성을 제거할 때 각 보석이 일반 수식의 "3×3 보석 폭발" 효과까지 발생시키는지 여부.

현재 확정된 것은:
- 타일 자체는 제거하지 않음
- 보석 속성만 제거
- 제거된 보석 수 n만큼 숫자 전체 상승

## 11. 연쇄 콤보 상한

[미정] 6스택 이상의 효과.

현재 1~5스택만 기획되어 있다.

구현은 6 이상이 발생해도 오류가 나지 않도록 방어적으로 설계해야 하며 실제 게임 효과는 미정 상태를 유지한다.

## 12. 능력과 타일 고유 속성

한가은의 보석/망치 효과는 숫자 타일의 고유 숫자 속성을 변경하지 않는다.

숫자 상승 역시 현재 숫자값만 변경한다.

고유 숫자 속성을 변경하는 것은 현재 기획상 유니크9의 예외다.
