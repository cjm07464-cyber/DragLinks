# Drag Links! — Hangaeun Ability

> 문서 버전: 0.3  
> 기준일: 2026-08-25

## 1. 캐릭터

이름: 한가은

- 고등학교 1학년
- 특별상담지원부 S.A.V.E 신입
- 수학을 자신의 강점으로 생각함
- 다른 사람의 내면 세계에서 산술 퍼즐 방식으로 문제를 해결함

[확정] 주인공 외형은 별도로 공유된 캐릭터 시안의 B안이 채택되었다.

이 문서에서는 외형을 묘사하지 않는다.

## 2. 마스코트와 무기

[확정] 한가은의 마스코트는 Link 후 내면 세계에서 **망치**로 변한다.

한가은의 퍼즐 능력은 보드의:
- **보석 숫자 타일**
- **망치 연산자 타일**

을 이용한다.

## 3. 특수 속성 주체

[확정]
- 보석 속성 → 숫자 타일
- 망치 속성 → 연산자 타일

보석/망치는 원래 타일의 숫자값/숫자 속성/연산자 종류를 대체하지 않는다.

추가 특수 상태로 취급한다.

## 4. 게임 시작 및 턴 종료 기본 능력

발동 타이밍:
- 게임 최초 시작 시
- 한 턴의 모든 계산, LINKING, 연쇄 콤보 정산이 완전히 끝난 뒤

효과:
1. 현재 보드의 **보석이 아닌 숫자 타일** 중 무작위 1개에 보석 속성 부여
2. 현재 보드의 **망치가 아닌 연산자 타일** 중 무작위 1개에 망치 속성 부여

[확정] 각각 한 개만 선택한다.

[확정] 이미 보석/망치인 타일은 후보에서 제외한다.

[확정] 기존 보석/망치는 해당 상태가 제거되거나 타일이 사라질 때까지 유지된다.

[현재안] 해당 종류의 유효 후보가 하나도 없으면 그 부여는 건너뛴다.

## 5. 수식 안의 망치와 보석

[확정] 하나의 정상 수식 안에 다음 두 요소가 모두 포함되면 한가은의 수식 능력이 발동한다.

- 망치 속성을 가진 연산자
- 보석 속성을 가진 숫자 타일

망치와 보석이 수식에서 바로 붙어 있을 필요는 없다.

## 6. 망치의 역할

[확정] 망치는 트리거 역할을 한다.

[확정] 수식에 망치가 여러 개 있어도 드래그 순서상 가장 앞에 있는 망치 하나가 발동 주체가 된다.

[확정] 망치 하나는 같은 수식 안의 보석을 최대 3개까지 터뜨릴 수 있다.

[미정] 수식에 보석이 4개 이상 들어왔을 때 어떤 3개를 우선할지.

## 7. 일반 수식 보석/망치 능력 — 최신 확정안

보석 숫자 타일이 망치 효과의 대상으로 발동하면 해당 보석을 중심으로 **3×3 주변 영역**을 확인한다.

[확정] 현재 드래그 수식에 포함된 타일은 주변 영역 판정에서 제외한다.

### 주변이 Number일 때

이제 주변 Number의 숫자값을 `+1` 하지 않는다.

[확정] **주변에서 발견된 Number 타일 하나당, 현재 보드의 Number 타일 중 무작위 하나에게 Gem 속성을 부여하는 시도를 1회 발생시킨다.**

예:
- 해당 Gem 주변의 유효한 Number가 3개라면
- 전역 보드 Number 대상으로 Gem 부여 시도 3회

즉 주변 Number 자신을 반드시 Gem으로 바꾸는 규칙이 아니다.

[확정] 이 능력으로 직접 숫자값 `+1`을 주는 효과는 폐기되었다.

[현재안] 이미 Gem인 Number에 중복 부여하지 않도록 실제 랜덤 후보는 비Gem Number에서 고르는 방향이 자연스럽다. 최종 구현 전 필요하면 확정한다.

[미정] 전역 랜덤 Gem 대상에서 현재 드래그 수식 경로의 Number도 제외할지 여부.

### 주변이 Operator일 때

[확정] 주변의 일반 Operator 타일 **그 자체**에 Hammer 속성을 부여한다.

[확정] 이미 Hammer인 Operator는 그대로 유지한다.

### 공통

[확정] 새로 Gem/Hammer가 된 타일이 즉시 다시 폭발하는 추가 연쇄는 발생하지 않는다.

[확정] 수식 계산과 점수 처리를 먼저 완료한 뒤 보석/망치 효과를 처리한다.
## 8. 연쇄 콤보 Runtime

[확정] 한가은은 `0~4`의 현재 연쇄 콤보 스택을 턴을 넘어 유지한다.

LINKING Line은 바로 스택 효과를 실행하는 것이 아니라 **콤보 정산 대기 횟수**를 1개 만든다.

현재 보드의 LINKING을 모두 해결한 뒤:
- Pending 1개 소비
- 현재 스택 +1
- 해당 단계 효과 발동

을 반복한다.

5스택 효과 발동 후 현재 스택은 0으로 초기화된다.

남은 Pending은 사라지지 않고 0스택부터 계속 처리한다.

## 9. 1스택

현재 보드의 **보석이 아닌 숫자 타일** 중 무작위 최대 2개에 보석 속성을 부여한다.

후보가 2개보다 적으면 가능한 후보까지만 처리한다.

## 10. 2스택

현재 보드의 **보석이 아닌 숫자 타일** 중 무작위 최대 5개에 보석 속성을 부여한다.

후보가 5개보다 적으면 가능한 후보까지만 처리한다.

## 11. 3스택

현재 보드의 **보석이 아닌 숫자 타일** 중 무작위 최대 7개에 보석 속성을 부여한다.

후보가 7개보다 적으면 가능한 후보까지만 처리한다.

## 12. 4스택 — 보석 숫자 강화

1. 현재 보드에 존재하는 보석 숫자 타일 개수를 `n`으로 계산한다.
2. 현재 모든 보석 숫자 타일의 **현재 숫자값을 각각 +n** 한다.

예:
- 현재 보석 숫자 6개
- `n = 6`

보석 숫자:
- 11 → 17
- 4 → 10
- 28 → 34

[확정] 보석 속성은 제거하지 않는다.

[확정] 보석이 아닌 숫자는 이 4스택 +n의 대상이 아니다.

[확정] 상승변화이며 NumberIdentity/색은 유지한다.

## 13. 5스택 — 보석 파괴 및 전체 성장

5스택은 일반 단계와 달리 보드를 물리적으로 변화시킨다.

순서:

1. 현재 보드의 **보석이 아닌 숫자 타일** 중 무작위 최대 11개에 보석 속성 부여
2. 현재 모든 보석 숫자 타일의 파괴 직전 현재 숫자값을 합산하여 `S` 저장
3. 현재 모든 보석 숫자 타일을 **실제 파괴**
4. 현재 연쇄 콤보 스택을 0으로 초기화
5. Gravity
6. Refill
7. LINKING 탐색
8. 새 LINKING이 있으면 모두 연산/사용 처리하며 제거/Gravity/Refill 반복
9. 이 추가 LINKING LineCount를 콤보 정산 대기 횟수에 추가
10. 더 이상 LINKING이 없으면 현재 보드의 **모든 숫자 타일 현재 숫자값을 각각 +S**
11. 남아 있는 콤보 정산 대기 횟수 처리 재개

## 14. 5스택 파괴의 판정

5스택에서 파괴되는 보석 숫자는:

- 연산 X
- 사용 X
- 파괴 O

따라서 유니크1 사용 카운트에는 포함되지 않는다.

중요:
과거의 "보석 속성만 제거" 안은 폐기되었다.

이번 5스택에서는 숫자 타일 자체가 실제로 사라진다.

## 15. 5스택 `S` 기준

`S`는 **실제로 5스택에서 파괴되는 모든 보석 숫자 타일의 파괴 직전 CurrentValue 합**이다.

예:
파괴 대상:
- 11
- 8
- 20
- 4

`S = 43`

보석 파괴 후 Gravity/Refill/LINKING을 모두 해결한 최종 보드에서:

모든 현재 숫자 타일:
`CurrentValue += 43`

새 Refill로 생성되어 최종 보드에 남아 있는 숫자도 +43 대상이다.

추가 LINKING으로 이미 사용/제거된 숫자는 +43 대상이 아니다.

## 16. 5스택과 추가 LINKING

보석 실제 파괴로 빈칸이 생기므로 새로운 LINKING이 발생할 수 있다.

[확정] 이 LINKING은 정상적인 LINKING이다.

따라서:
- 연산 O
- 사용 O
- 라인 수만큼 새 Pending Combo 추가

추가 LINKING을 전부 해결한 뒤에만 `+S`를 적용한다.

## 17. 한 Action에서 여러 번 5스택

[확정] Pending이 충분하면 한 Action 처리 안에서 5스택이 여러 번 발생할 수 있다.

5스택 도달 후:
- 0으로 초기화
- 남은 Pending은 계속 존재
- 다시 1→2→3→4→5 진행 가능

6스택 개념은 사용하지 않는다.

## 18. 일반 보석 폭발과 5스택 강제 파괴

[미정] 5스택에서 보석 숫자를 강제 파괴할 때, 일반 수식 보석 폭발의 3×3 보석/망치 변환 효과까지 함께 발생시키는지 여부.

현재 확정:
- 타일은 실제 파괴
- 연산/사용 아님
- `S` 합산 대상
- Gravity/Refill 발생

## 19. 능력과 고유 숫자 속성

한가은의:
- 보석/망치 부여
- 4스택 +n
- 5스택 +S

는 NumberIdentity를 변경하지 않는다.

현재 고유 숫자 속성을 변경하는 예외는 유니크9다.
