# Drag Links! — Drag Input Rules

> 문서 버전: 0.1  
> 기준일: 2026-08-25

## 1. 기본 입력

[확정] Drag Links!는 PC 게임이다.

[현재안] 기본 퍼즐 입력은 마우스/포인터 드래그를 중심으로 설계한다.

[확정] 한 번의 유효한 드래그 행동이 완료되고 손을 떼면 1턴을 소비한다.

[확정] 유효하지 않은 입력은 턴을 소비하지 않는다.

## 2. 최대 연결 수

[확정] 기본 최대 연결 수는 **5타일**이다.

시작 타일도 1개로 계산한다.

[확정] 최대 연결 수는 향후 업그레이드될 수 있으므로 하드코딩된 상수로 고정하지 않는다.

## 3. 방향

[확정] 드래그 연결은 8방향이다.

- 상
- 하
- 좌
- 우
- 좌상
- 우상
- 좌하
- 우하

## 4. 경로 규칙

[확정] 한 번 선택한 타일은 같은 드래그 안에서 다시 사용할 수 없다.

[확정] 드래그 경로는 자기 자신과 교차하지 않는다.

[확정] 현재 마지막 타일에서 바로 이전 타일 방향으로 역순 드래그하면 마지막 선택을 취소할 수 있다.

예:
- `A → B → C`
- C에서 B로 되돌아감 → C 선택 취소
- B에서 A로 되돌아감 → B 선택 취소

이 되돌리기 UX는 전작에서 계승한다.

## 5. 숫자 타일로 시작한 경우

드래그 시작 타일이 숫자라면 **수식 드래그 모드**가 된다.

[확정] 연결 규칙:

`숫자 → 연산자 → 숫자 → 연산자 → 숫자 ...`

[확정] 숫자로 시작한 수식은 숫자로 끝나야 한다.

예:
- `1 + 2` → 유효
- `1 + 2 × 3` → 유효
- `1 +` → 무효

[확정] 현재 선택 타일에서 규칙상 연결할 수 없는 타일은 아예 다음 경로로 선택되지 않도록 한다.

## 6. 연산자 타일로 시작한 경우

드래그 시작 타일이 연산자라면 **연산자 합성 모드**가 된다.

[확정] 현재는 연산자 2개까지만 연결한다.

[확정] 현재 확정 조합:
- `+ + → ×`
- `- - → ÷`

[확정] 첫 번째 연산자 타일은 제거된다.

[확정] 결과 연산자는 두 번째로 선택한 타일 위치에 남는다.

[확정] 연산자 합성도 유효 행동이면 1턴을 소비한다.

[미정]
- `× ×` 결과
- `÷ ÷` 결과
- 서로 다른 연산자끼리의 연결
- 3개 이상 연산자 합성

## 7. 잘못된 드래그

[확정] 미완성 수식이나 유효하지 않은 행동으로 손을 떼도 턴은 소비하지 않는다.

[현재안] 입력 단계에서 가능한 한 잘못된 경로 자체가 형성되지 않도록 한다.

## 8. 드래그 확정 시 전달해야 할 정보

기술 구현에서는 드래그 종료 시 다음 정보를 다른 시스템이 사용할 수 있어야 한다.

- 선택된 타일 순서
- 선택된 타일 좌표
- 행동 종류: 수식 / 연산자 합성
- 유효 여부
- 드래그에 포함된 보석 숫자 타일
- 드래그에 포함된 망치 연산자 타일

Drag 시스템이 점수나 캐릭터 효과를 직접 계산하지 않는다.

## 9. 입력 잠금

[확정] 수식 계산, 보드 제거, 중력, 충당, LINKING, 연쇄 콤보 등의 자동 처리가 진행 중일 때 새로운 드래그 입력을 받지 않는다.

턴이 다시 입력 가능 상태가 된 뒤 다음 드래그를 허용한다.
