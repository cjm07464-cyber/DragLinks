# Drag Links! — Turn Flow

> 문서 버전: 0.1  
> 기준일: 2026-08-25

이 문서는 Drag Links!의 **처리 순서**를 정의한다.

## 1. 한 턴의 기준

[확정] 유효한 플레이어 행동 1회가 1턴을 소비한다.

유효 행동:
- 정상 수식 드래그
- 정상 연산자 합성

무효 행동:
- 미완성 수식
- 규칙에 맞지 않는 드래그
- 취소된 드래그

무효 행동은 턴을 소비하지 않는다.

## 2. 게임 시작 기본 순서

현재 기준:

1. Stage 데이터 로드
2. 보드 생성
3. 초기 무료 유니크 선택
4. 한가은 기본 능력 최초 발동
   - 보석이 아닌 숫자 타일 중 무작위 1개에 보석 부여
   - 망치가 아닌 연산자 타일 중 무작위 1개에 망치 부여
5. 첫 입력 가능 상태 진입

[미정] 초기 보드에 LINKING이 존재할 경우 최초 능력 전에 자동 처리할지 여부.

## 3. 수식 행동 턴

1. 입력 대기
2. 플레이어 드래그
3. 드래그 유효성 확정
4. 수식 계산
5. 점수 계산 및 누적
6. 한가은의 수식 내 망치/보석 능력 판정 및 처리
7. 사용 수식 타일 제거
8. 중력
9. 새 타일 충당
10. LINKING 자동 처리 루프
11. 최종 연쇄 콤보 스택 확정
12. 캐릭터 연쇄 콤보 효과 처리
13. Stage/Enemy 턴 종료 기믹 처리
14. 턴 종료
15. 한가은 기본 능력 발동
16. 다음 턴 입력 가능 상태

## 4. 연산자 합성 턴

1. 입력 대기
2. 연산자 2개 드래그
3. 유효 합성 판정
4. 첫 번째 연산자 제거
5. 두 번째 위치의 연산자를 합성 결과로 변경
6. 빈칸 처리
7. 중력
8. 새 타일 충당
9. LINKING 자동 처리 루프
10. 최종 연쇄 콤보 스택 확정
11. 캐릭터 연쇄 콤보 효과 처리
12. Stage/Enemy 턴 종료 기믹 처리
13. 턴 종료
14. 한가은 기본 능력 발동
15. 다음 턴 입력 가능 상태

[확정] 연산자 합성 자체는 점수를 얻는 산술식이 아니다.

## 5. LINKING 루프

`LINKING 탐색 → 제거 → 중력 → 충당 → 재탐색`

을 더 이상 LINKING이 없을 때까지 반복한다.

각 라인 수를 연쇄 콤보 스택에 더한다.

루프 종료 후 최종 스택 효과를 한 번 실행한다.

## 6. 턴 종료 캐릭터 능력

한가은의 기본 능력은 **모든 계산과 LINKING/연쇄 콤보 처리가 끝난 뒤** 발동한다.

그 후 다음 턴이 시작된다.

## 7. 적 기믹 타이밍

[현재안] 적/스테이지의 N턴 기믹은 연쇄 콤보 처리 후, 한가은의 턴 종료 기본 능력보다 먼저 처리하는 방향으로 둔다.

[미정] 동시에 여러 End Turn 효과가 존재할 경우의 상세 Priority.

## 8. 목표 점수 도달 타이밍

[확정] 누적 점수가 목표 점수 이상이면 승리 조건이 충족된다.

[미정] 수식 점수 획득 순간 승리 조건을 만족했을 때 이후 망치/보석, LINKING, 연쇄 콤보까지 처리한 뒤 종료할지 즉시 클리어 플로우로 전환할지.

## 9. 입력 잠금

자동 처리 단계에서는 입력을 잠근다.

예:
- 점수 연출
- 보석/망치 효과
- 타일 제거
- 중력/충당
- LINKING
- 연쇄 콤보
- 적 기믹

다음 턴 입력 가능 상태가 명시적으로 열릴 때만 드래그를 허용한다.

## 10. 기술 구현 권장 상태

예시 `TurnPhase`:
- Idle
- Dragging
- ResolvingAction
- ResolvingScore
- ResolvingCharacterFormulaEffect
- SettlingBoard
- ResolvingLinking
- ResolvingChainCombo
- ResolvingStageEffect
- ResolvingEndTurn
- Transitioning

정확한 enum 이름은 구현 시 조정 가능하지만 **처리 순서를 명시적인 상태로 관리한다는 원칙**은 유지한다.
