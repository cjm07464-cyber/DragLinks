# Drag Links! — Formula & Score Rules

> 문서 버전: 0.1  
> 기준일: 2026-08-25

## 1. 수식 계산

숫자로 시작한 유효 드래그는 하나의 산술식으로 계산한다.

[확정] 일반적인 사칙연산 우선순위를 사용한다.

1. 곱셈 `×`, 나눗셈 `÷`
2. 덧셈 `+`, 뺄셈 `-`

[확정] 같은 우선순위에서는 왼쪽부터 계산한다.

예:
`8 ÷ 4 × 2`
→ `(8 ÷ 4) × 2`
→ `4`

## 2. 숫자 타일의 계산값

수식에는 각 숫자 타일의 **현재 숫자값**을 사용한다.

숫자 타일의 고유 숫자 속성이나 색은 수식의 산술값을 대신하지 않는다.

## 3. 음수

[확정] 계산 중간에 음수가 나오는 것은 허용한다.

[확정] 최종 결과가 양수라면 정상적으로 처리한다.

[미정] 최종 수식 결과가 음수일 때 획득 점수 및 추가 효과.

## 4. 0

[확정] 최종 수식 결과가 0이면 획득 점수는 0이다.

[미정] 향후 숫자 타일 자체의 현재값이 0이 될 수 있는 효과가 추가될지 여부.

[현재안] 0으로 나누기가 발생할 수 있는 상태가 생길 경우 입력/계산 단계에서 안전하게 차단해야 한다.

## 5. 최종 점수 공식

- **A**: 모든 현재 효과가 반영된 최종 산술 결과
- **B**: A의 유효 약수에 따라 결정되는 최종 점수 배율

`최종 점수 = A × B`

## 6. 약수 배율

A의 약수 중 1~9 사이 값만 **유효 약수**로 사용한다.

| 유효 약수 | 표시 배율 | 실제 합산 추가 배율 |
|---:|---:|---:|
| 1 | 100% | +0% |
| 2 | 101% | +1% |
| 3 | 102% | +2% |
| 4 | 103% | +3% |
| 5 | 104% | +4% |
| 6 | 105% | +5% |
| 7 | 106% | +6% |
| 8 | 107% | +7% |
| 9 | 108% | +8% |

`B = 100% + 유효 약수들의 추가 배율 합계`

각 표시 배율을 통째로 더하지 않는다.

## 7. 계산 예시

A = 24.

24의 약수:
`1, 2, 3, 4, 6, 8, 12, 24`

유효 약수:
`1, 2, 3, 4, 6, 8`

추가 배율:
`0 + 1 + 2 + 3 + 5 + 7 = 18%`

따라서:
`B = 118% = 1.18`

최종 점수:
`24 × 1.18 = 28.32`

## 8. 소수점 규칙

[확정] 최종 점수는 소수점 둘째 자리까지 사용한다.

[확정] 소수점 셋째 자리에서 반올림한다.

예:
- `28.324 → 28.32`
- `28.325 → 28.33`

[확정] 표시 시 불필요한 끝자리 0은 생략한다.

예:
- `103.10 → 103.1`

## 9. 누적 점수와 승리

[확정] 유효 수식에서 얻은 최종 점수를 현재 스테이지 누적 점수에 더한다.

[확정] 누적 점수가 스테이지 목표 점수 이상이 되면 승리 조건을 만족한다.

[미정] 목표 점수에 도달한 순간 보드 후처리/LINKING/연쇄 콤보를 끝까지 연출한 뒤 종료할지, 즉시 스테이지 종료 상태로 전환할지.

## 10. 역수와 비정수

[현재안] Stage 2 이후 역수 요소를 도입할 계획이 있다.

[미정]
- 역수 타일의 정확한 형태
- 역수의 고유 숫자 속성
- 분수 계산 방식
- A가 비정수일 때 약수 배율 B 계산 방식
