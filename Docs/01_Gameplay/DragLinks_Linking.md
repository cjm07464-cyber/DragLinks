# Drag Links! — LINKING & Chain Combo

> 문서 버전: 0.1  
> 기준일: 2026-08-25

## 1. 개념 구분

### 연쇄 보너스
수식/보드 처리가 끝난 뒤 타일이 이동하고 새 타일이 충당되는 과정에서, **가로 또는 세로 한 줄 전체가 숫자 타일**이 되어 자동으로 터지는 현상.

게임 연출 표기:
**LINKING!**

### 연쇄 콤보
한 번의 자동 보드 정산 구간에서 발생한 LINKING 라인 수를 누적한 최종 스택.

## 2. LINKING 조건

[확정] 한 행 전체가 숫자 타일이면 LINKING 1줄.

[확정] 한 열 전체가 숫자 타일이면 LINKING 1줄.

[확정] 숫자값은 서로 달라도 된다.

[확정] 고유 숫자 속성/색도 서로 달라도 된다.

즉, 판정은 "같은 숫자"가 아니라 **타일 종류가 모두 Number인가**를 본다.

[현재안] 대각선은 LINKING 라인 판정에 사용하지 않는다.

## 3. 한 번의 LINKING 처리

1. 현재 보드에서 모든 LINKING 라인을 찾는다.
2. 발견된 각 라인을 연쇄 보너스 1줄로 계산한다.
3. 화면에 LINKING! 연출을 표시한다.
4. 라인에 포함된 타일을 제거한다.
5. 중력을 적용한다.
6. 빈칸을 새 타일로 충당한다.
7. 다시 LINKING 라인을 검사한다.

## 4. 교차 라인

[확정] 가로와 세로 LINKING이 교차할 수 있다.

[확정] 연쇄 콤보 계산에서는 각 라인을 별도로 센다.

예:
- 가로 1줄
- 세로 1줄
- 중앙에서 교차
→ 연쇄 콤보 증가량 2

[확정] 실제 제거 대상 타일은 합집합으로 처리하여 교차 타일을 한 번만 제거한다.

## 5. 연속 LINKING

첫 LINKING 제거 후 중력과 충당 결과로 다시 숫자 한 줄이 만들어질 수 있다.

그 경우 다시 LINKING을 처리한다.

예:
- Wave 1: 2줄
- 제거/중력/충당
- Wave 2: 1줄
- 제거/중력/충당
- 이후 없음

최종 연쇄 콤보:
`3스택`

## 6. 연쇄 콤보 확정 시점

[확정] LINKING이 더 이상 하나도 발생하지 않을 때 자동 줄 처리 루프를 종료한다.

[확정] 그 시점까지 발생한 LINKING 라인 수의 합을 최종 연쇄 콤보 스택으로 확정한다.

[확정] 최종 스택에 해당하는 플레이어 캐릭터의 연쇄 콤보 효과를 **한 번** 발동한다.

예:
3줄이 터지고 더 이상 LINKING이 없으면 → 3스택 효과 1회.

1스택, 2스택, 3스택 효과를 순서대로 각각 실행하는 구조가 아니다.

## 7. 캐릭터 공통 규칙과 분리

LINKING 시스템이 알아야 하는 것은 다음까지다.

- 현재 발생한 라인 목록
- 라인 수
- 실제 제거할 중복 없는 타일 목록
- 누적 연쇄 콤보 스택
- 자동 연쇄 종료 여부

LINKING 시스템이 직접 한가은의 보석 효과를 실행하지 않는다.

## 8. 한가은 연쇄 콤보 요약

상세 내용은 `Docs/02_Characters/DragLinks_Hangaeun.md`를 따른다.

- 1스택 → 보석 2개 부여
- 2스택 → 보석 5개 부여
- 3스택 → 보석 7개 부여
- 4스택 → 보석 9개 부여 후 전체 보석 속성 제거 및 숫자 강화
- 5스택 → 보석 11개 부여 후 전체 보석 속성 제거 및 숫자 강화

[미정] 6스택 이상 처리.

## 9. 4~5스택의 보석 제거는 타일 제거가 아니다

[확정] 연쇄 콤보 효과에서 "모든 보석이 터진다"는 말은 **숫자 타일 자체를 삭제한다는 뜻이 아니다.**

보석 속성만 사라진다.

따라서:
- 타일 위치 유지
- 현재 숫자값 유지
- 고유 숫자 속성 유지
- 보석 속성만 제거
- 빈칸 없음
- 이 효과 때문에 중력/충당 없음
- 이 효과 때문에 새로운 LINKING 검사를 다시 시작하지 않음

[미정] 연쇄 콤보의 전체 보석 속성 제거가 일반적인 "보석 폭발 3×3 효과"까지 각각 발생시키는지 여부.

## 10. 안전장치

[현재안] 자동 LINKING 루프에는 비정상적인 무한 반복을 감지할 수 있는 안전장치/최대 반복 보호가 필요하다.

이는 정상적인 게임 규칙을 제한하기 위한 밸런스 숫자가 아니라 개발/QA 기술 안전장치다.
