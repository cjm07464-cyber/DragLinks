# Drag Links! — Board & Tile Rules

> 문서 버전: 0.1  
> 기준일: 2026-08-25

## 1. 보드

[미정] 최종 보드 크기는 다음 두 안을 검토 중이다.

- 7×6
- 8×6

[확정] 보드 크기는 데이터로 변경 가능해야 하며 코드에 특정 크기를 하드코딩하지 않는다.

[확정] 보드는 사각 격자 구조를 사용한다.

## 2. 보드 비주얼

[확정] 보드 및 보드 위 타일은 2D 에셋을 기본으로 사용한다.

[확정] 기본 타일 도형은 **모서리가 둥근 정사각형**이다.

[확정] 숫자와 연산자 문자는 타일 배경에 합쳐진 이미지가 아니라 별도의 에셋/표현 요소로 사용한다.

[확정] 같은 종류의 타일은 기본 도형을 통일하고 색과 표시 요소를 바꾼다.

## 3. 타일 종류

### 숫자 타일
- 기본 생성 숫자 1~9
- 1~9 각각 다른 고유 색
- 실제 계산에 사용되는 현재 숫자값을 가짐
- 숫자 고유 속성을 가짐
- 한가은 능력으로 보석 속성을 가질 수 있음

### 연산자 타일
- `+`
- `-`
- `×`
- `÷`
- 공통 한 가지 색 계열
- 한가은 능력으로 망치 속성을 가질 수 있음

## 4. 숫자의 현재값과 고유 숫자 속성

[확정] 숫자 타일에는 다음 두 개념이 따로 존재한다.

1. **현재 숫자값**
   - 화면에 표시되는 숫자
   - 실제 수식 계산에 사용되는 숫자
   - 게임 중 상승/하락/배율 등의 영향을 받을 수 있음

2. **고유 숫자 속성**
   - 이 타일이 1~9 중 어떤 숫자 계열인지 나타냄
   - 타일 색의 기준
   - 유니크 및 캐릭터 조건 판정의 기준

예:
- 파란색이 숫자 1 속성이라고 가정
- 파란 1이 +10을 받아 파란 11이 됨
- 계산 시 값은 11
- 숫자 1 속성 조건에는 계속 포함
- 색도 파란색 유지

[확정] 일반적인 숫자값 변화로 고유 숫자 속성은 변하지 않는다.

[확정] 현재 기획에서 고유 숫자 속성을 바꾸는 예외는 유니크9다.

## 5. 숫자 색

[확정] 숫자 1~9는 서로 다른 9개 색으로 구분한다.

[확정] 숫자값이 변해도 고유 숫자 속성이 유지되는 동안 색은 유지한다.

[현재안] 색각 다양성을 고려해 색 외의 보조 식별 요소를 도입할 의향이 있다.

[미정] 1~9의 최종 RGB 팔레트.

## 6. 보석과 망치

### 보석
[확정]
- 숫자 타일에만 부여할 수 있다.
- 팔각형 보석 이미지로 표현할 예정이다.
- 숫자값과 고유 숫자 속성은 그대로 유지한 채 추가되는 특수 속성이다.

### 망치
[확정]
- 연산자 타일에만 부여할 수 있다.
- 연산자 종류는 그대로 유지한 채 추가되는 특수 속성이다.

[미정] 망치 속성의 최종 비주얼 표시 방식.

## 7. 타일 상태 유지

[확정] 타일의 숫자값 변화, 보석, 망치 등의 상태는 해당 타일이 사용/제거되거나 효과로 해제되지 않는 한 유지된다.

새 타일이 충당될 때 기존 타일의 상태를 임의로 복제하지 않는다.

## 8. 사용 타일 제거

정상적인 수식을 사용하면 해당 수식에 포함된 타일들은 사용 처리 후 보드에서 제거된다.

연산자 합성의 경우:
- 첫 번째 연산자 타일은 제거
- 결과 연산자는 두 번째로 선택한 타일 위치에 남음

이후 빈칸에는 중력과 충당 처리가 적용된다.

## 9. 중력과 충당

[확정] 타일 제거 후 빈 공간이 생기면 타일이 보드의 중력 방향으로 이동한다.

[확정] 남은 빈칸에는 새 타일이 충당된다.

[현재안] 전작에서 사용한 보드 생성/중력/충당 알고리즘은 구현 레퍼런스로 참고하되, Drag Links! 구조에 맞게 새로 작성한다.

[임시] 초기 숫자/연산자 생성 확률은 전작 최종 구현을 참고값으로 시작할 수 있으나 Drag Links! 테스트 결과를 기준으로 조정한다.

## 10. LINKING 판정과 보드

[확정] 가로 또는 세로의 **한 줄 전체가 숫자 타일**이면 연쇄 보너스(LINKING!) 조건이다.

숫자값은 같을 필요가 없다.

고유 숫자 속성이나 색도 같을 필요가 없다.

예:
`1 / 7 / 21 / 3 / 9 / 42`

전부 숫자 타일이면 한 줄 조건을 만족한다.

[확정] 현재 LINKING은 가로/세로 기준이다.

[현재안] 대각선은 드래그에는 사용하지만 LINKING 라인 판정에는 사용하지 않는다.

## 11. 초기 보드 생성 관련

[미정] 게임 시작 직후 이미 LINKING 라인이 존재하는 보드를 허용할지 여부.

[현재안] 보드 생성기는 향후 시작 보드 검증 규칙을 추가할 수 있는 구조로 만든다.

## 12. 보드 시스템이 알아서는 안 되는 것

공통 Board 시스템은 다음을 직접 하드코딩하지 않는다.

- 한가은의 연쇄 콤보 단계별 효과
- 유니크1의 1 사용 카운트
- Stage_01 적 기믹
- Story 진행

Board는 현재 타일 상태와 보드 변화를 제공하고, 캐릭터/유니크/스테이지 시스템은 별도 계층에서 이를 사용한다.
